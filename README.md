# Library

📚 Interactive library management app that lets users add, remove, and organize books through a dynamic JavaScript interface.

## Features

- Add new books through a custom form
- Remove books from the library
- Toggle reading status
- Dynamic book card generation
- Responsive and user-friendly interface
- Instant UI updates without page reloads

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## What I Learned

- Object constructors and object-oriented programming concepts
- DOM manipulation
- Dynamic element creation
- Form handling and validation
- Event delegation
- Managing application state

## Project Goal

This project was built as part of The Odin Project curriculum to practice JavaScript objects, DOM manipulation, and building interactive applications.
